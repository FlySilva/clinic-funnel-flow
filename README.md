# Clinic Funnel Flow

Construa uma aplicação interativa de funil de vendas para WhatsApp e CRM para clínicas. A interface deve ser dividida em duas áreas principais: de um lado, um simulador visual de WhatsApp onde o usuário pode interagir com o bot de triagem (menu de opções 1 a 5 para tratamentos, perguntas de qualificação, coleta de nome completo e melhor período de atendimento); do outro lado, um painel CRM estilo Kanban com colunas (Novo Lead, Em Triagem, Qualificado, Agendado, Desqualificado) que atualiza automaticamente em tempo real conforme o lead avança na conversa no WhatsApp. Inclua detalhes do lead ao clicar no card, tags de procedimento, status e simulação de webhook de integração.
